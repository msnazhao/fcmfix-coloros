# FCMFix-Zygisk 13.2.0

基于上游 ByteJuno/fcmfix-coloros 13.2，改为 NeoZygisk 模块。**不能覆盖安装 LSPosed 版**：先在 LSPosed 中停用并卸载旧版，再刷入本版模块压缩包。

- 不再需要 LSPosed，需要已验证的 NeoZygisk。应用打包在模块压缩包里，刷入时自动安装。
- 旧配置不会导入，请在“应用”页重新放行。
- 模块自带启动保护：连续开机失败会自动停用自己。支持 NeoZygisk 的晚加载。
- root 管理器里有两个按钮：Action 检查模块、应用和 Hook 的运行状态；配置按钮直接打开应用。
- 状态页与应用页的“包含 FCM 的应用”数量统一用同一条规则，并显示其中有多少个已自动放行。
- “关于”页更新了项目主页、提交问题、检查更新的地址，并注明上游。
- 版本号规则：前两段是上游版本，最后一段是本项目修订号。
